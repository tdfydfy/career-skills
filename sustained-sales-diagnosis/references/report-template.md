# 持销期专题诊断与改善方案模板

持销专题沿用统一的五部分项目诊断结构。持销多因素分析、干预阶梯、房车同售和老业主风险是可嵌入的专题深度，不另建一套报告目录。

## 第一部分：管理摘要

1. 当前年度及月度业绩判断、异常开始时间和影响范围。
2. 一至三条主因果链、主因关系及重要放大因素。
3. 项目策略倾向、适用条件、主要风险和不做事项。
4. 数据分析与用户、管理者、一线专业判断的一致或冲突之处。
5. 项目可直接执行、地区需要协调和集团需要决策的关键事项。

管理摘要只放结论，不复制第三、四部分的完整论证。

## 第二部分：目标与缺口

- 年度认购、签约目标，累计完成、全年预计和剩余缺口。
- 月度认购、签约任务，实际完成、全月预计和短期补救压力。
- 缺口发生的月份、产品或面积段、楼栋房源、渠道、销售人员和漏斗环节。
- 项目利润要求，以及政府沟通、配套落地、换地、精装等专项任务目标。
- 异常前后、开盘至今、近三个月和近十二周等适用对比窗口。

本部分回答：差多少、差在哪里、何时开始，以及当前经营任务是什么。

## 第三部分：项目客观分析

只展开真正影响结论的模块，数据、来源、专业判断、假设和缺口随分析呈现，不另设数据依据章节。

### 市场与竞争

- 市场按月分析新房供应、成交、均价和去化周期，以及二手房挂牌、成交和折扣，并形成正确口径的年度汇总。
- 竞品按具体项目分析基本信息、产品、推售动作、价格、货量、展示、渠道、经营策略及效果，与城市板块宏观市场分开。

### 客户与销售

- 成交客户特征、未成交首要及伴随原因、当前客储量质和竞品流向。
- 年度及月度认购、签约完成与预计；来访—认筹—认购—签约同队列漏斗。
- 按产品、面积段、楼栋房源、渠道和销售人员拆解缺口，不按绝对业绩简单排名。

### 货量与价格

- 使用含全盘合计行的分楼栋统计表，以及注明日期、来源、图例和已售口径的单栋或多栋房号销控图。
- 区分优质房源滞销和顶底、遮挡等抗性房源积压。
- 复盘整盘累计或近三个月分业态、分户型实际成交套数、面积、金额和均价；底价、破底折扣和审批只用于检验历史定价。
- 后续可实现价格必须同时说明成交量、期限、客户和市场假设。

### 利润、团队、执行与专项任务

- 项目净利润、毛利润和成本利润率按正式目标或启动会基准、最新动态、方案后预测比较，其他财务指标按需补充。
- 团队查看操盘手、策划、销售经理、销售、拓客、签约、网络岗位配置及胜任度；重点分析销售人数、周均接待、月均成交及人均值、弱项岗位和年度薪酬费用。
- 重要节点和关键行动区分计划、实际执行和执行后费用、效果、客储及销售结果；缺少项目确认时标记未知。
- 专项任务逐项呈现目标、节点、进展、阻碍、责任、下一动作和支持事项。

### 适用专题

房车同售、权益组合、老业主风险或交付问题只有在影响本项目主因和策略时才展开，并嵌入客户、货量、价格、利润或动作分析，不作为固定独立章节。

## 第四部分：综合诊断与策略动作

### 总述

- 整体经营判断。
- 一至三条核心矛盾的主次或因果关系。
- 基于项目客观条件的策略倾向、适用条件和风险。

### 按主因分述

每条主因依次闭合：

1. 主因及受影响客户、房源或漏斗环节。
2. 第三部分证据、反证和专业判断。
3. 对应项目策略、备选情景、选择理由和不做事项。
4. 关键行动、项目责任人、预算、目标结果、复盘和停止或升级规则。
5. 所需地区支持或集团决策。

干预阶梯用于选择动作，不按 L1 至 L6 顺序机械铺陈。行动周期按项目窗口和动作验证需要确定；两周、四周、八周只能作为适用时的参考，不是固定目录。

价格、权益、产品、房车同售等情景随对应主因嵌入，并在同一情景内对齐成交、合约、回款、库存、费用和利润影响。

## 第五部分：小结

不新增分析，只汇总：

1. 项目可直接执行事项。
2. 地区协调支持事项。
3. 集团决策审批事项。

每项保留责任人、时点或决策期限；没有相应事项时明确写“无”。

## 附件

事实台账、专业判断记录、指标趋势、市场月度及年度汇总、客户底表、竞品监测、分楼栋货量表、房号销控图、价格利润情景、团队与薪酬底表、专项任务记录、动作费用复盘、适用时的车位台账、老业主风险表和因果验证记录。
