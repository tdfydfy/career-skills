# 持销多因素诊断模型

## 诊断单位

不要只诊断“项目卖不动”。把问题拆到具体时间、客户、房源和漏斗环节：

`触达不足 → 到访不足 → 客户质量不足 → 价值认同不足 → 房源不匹配 → 承价不足 → 决策条件未完成 → 成交/签约/回款失败`

## 外部因素

| 维度 | 重点问题 | 典型证据 |
| --- | --- | --- |
| 市场与政策 | 容量、信心、信贷、交易政策是否变化 | 供销价、库存周期、贷款和政策时间线 |
| 竞争 | 新竞品、降价、加佣、展示或产品是否改变客户选择 | 竞品成交、带看、价格、客户流向 |
| 客户 | 主力客群、预算、动机、生活半径和决策周期是否变化 | 来访结构、预算、抗性和流失原因 |
| 产品趋势 | 本项目面积、功能、配置或交付是否落后或错配 | 同面积竞品、客户评价、退选原因 |
| 渠道生态 | 中介、媒体和合作资源的覆盖、成本和偏好是否变化 | 报备、带看、有效客户、竞品政策 |

## 内部因素

| 维度 | 重点问题 | 典型证据 |
| --- | --- | --- |
| 定位与策略 | 客群、主力房源和阶段任务是否明确 | 策略版本、房源角色、资源分配 |
| 产品与货量 | 剩余库存是否天然变难，推售结构是否错位 | 分楼栋户型去化、抗性、待推货量 |
| 价格与权益 | 净价、总价、价差和资源是否支持价值 | 房号成交、竞品、承价、底价 |
| 价值与传播 | 传播方向和价值点是否回答客户问题 | 内容主题、客户复述、留资与复访 |
| 展示与体验 | 展示是否过时、不完整或无法证明卖点 | 动线观察、客户停留、展示验收 |
| 获客与渠道 | 客群选择、渠道组合和费效是否正确 | 分渠道漏斗、成本、客户质量 |
| 销售与团队 | 接待、挖需、讲解、跟进、逼定和能力是否达标 | 录音、盘客、个人转化、培训考核 |
| 激励与组织 | 指标是否驱动正确房源、车位和行为 | 佣金、考核、人员稳定、协同RACI |
| 执行与数据 | 策略是否按时、按质、可追踪执行 | 任务验收、CRM、稽核、复盘记录 |
| 交易与服务 | 签约、按揭、交付预期和投诉是否阻碍成交 | 逾期、退房、投诉、老业主反馈 |

## 前期得失复盘

对每个阶段形成四列：

| 事实 | 当时为何有效/无效 | 现在是否仍成立 | 对下一步意味着什么 |
| --- | --- | --- | --- |

特别区分：

- 开盘热度自然回落与真实策略失效。
- 好卖房源消耗后的库存难度上升与团队转化下降。
- 市场整体下滑与本项目相对份额下降。
- 渠道客户质量下降与案场承接能力不足。

## 因果验证

每个候选原因记录：

```yaml
candidate_cause:
  symptom: null
  evidence_for: []
  evidence_against: []
  affected_funnel_stage: null
  affected_customer_or_inventory: []
  timing_match: false
  controllability: high | medium | low
  confidence: high | medium | low
  validation_action: null
```

优先使用：

1. 时间一致性：原因先于结果发生。
2. 结构差异：受影响与未受影响客户、房源、渠道存在可解释差异。
3. 对照证据：市场或竞品没有同样下降，或同类项目表现不同。
4. 客户证据：去重客户底表、访谈和未成交原因支持。
5. 小范围实验：修复某因素后领先指标改善。

允许十多个因素共同作用，但管理结论应归并为一至三条主因果链，例如：

`竞品实景升级 → 本案价值证据不足 → 传播仍讲抽象品牌 → 客户复访下降 → 来访成交转化走弱`。

其余因素标记为放大因素、约束或待验证项，不强行全部归为根因。
