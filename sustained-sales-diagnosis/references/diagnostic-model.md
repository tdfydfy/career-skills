# 持销多因素诊断模型

## 诊断单位

不要只诊断“项目卖不动”。把问题拆到具体时间、客户、房源和漏斗环节：

`触达不足 → 到访不足 → 客户质量不足 → 价值认同不足 → 房源不匹配 → 承价不足 → 决策条件未完成 → 成交/签约/回款失败`

## 外部因素

| 维度 | 重点问题 | 典型证据 |
| --- | --- | --- |
| 市场与政策 | 城市及板块容量、供销价、库存周期、信心、信贷和交易政策是否变化 | 新房与二手房月度数据、年度汇总、贷款和政策时间线 |
| 竞争 | 具体竞品的推售、产品、价格、货量、展示、渠道或策略是否改变客户选择 | 竞品基本信息、成交、带看、价格、动作效果和客户流向 |
| 客户 | 主力客群、预算、动机、生活半径和决策周期是否变化 | 来访结构、预算、抗性和流失原因 |
| 产品趋势 | 本项目面积、功能、配置或交付是否落后或错配 | 同面积竞品、客户评价、退选原因 |
| 渠道生态 | 中介、媒体和合作资源的覆盖、成本和偏好是否变化 | 报备、带看、有效客户、竞品政策 |

## 内部因素

| 维度 | 重点问题 | 典型证据 |
| --- | --- | --- |
| 定位与策略 | 客群、主力房源和阶段任务是否明确 | 策略版本、房源角色、资源分配 |
| 产品与货量 | 剩余库存是否天然变难，推售结构是否错位；是优质房源仍滞销还是抗性房源自然积压 | 含合计行的分楼栋表、单栋或多栋房号销控图、垂直区段、户型去化、抗性和待推货量 |
| 价格与权益 | 过去实际成交量价是否匹配，后续价格能对应多少成交量 | 整盘或近三个月分业态分户型量价、宏观市场、客户承价、底价和破底折扣 |
| 价值与传播 | 传播方向和价值点是否回答客户问题 | 内容主题、客户复述、留资与复访 |
| 展示与体验 | 展示是否过时、不完整或无法证明卖点 | 动线观察、客户停留、展示验收 |
| 获客与渠道 | 客群选择、渠道组合和费效是否正确 | 分渠道漏斗、成本、客户质量 |
| 销售与团队 | 各岗位配置和胜任度是否匹配，销售人数、周均接待和月均成交是否反映过载、闲置或弱项岗位 | 编制、在岗、岗位判断、项目总量及人均接待成交、补强计划 |
| 激励与组织 | 佣金、底薪、年度薪酬费用和责任分工是否支持正确房源、车位和行为 | 佣金底薪标准、薪酬预测、考核、协同RACI |
| 执行与数据 | 策略是否按时、按质、可追踪执行 | 任务验收、CRM、稽核、复盘记录 |
| 交易与服务 | 签约、按揭、交付预期和投诉是否阻碍成交 | 逾期、退房、投诉、老业主反馈 |
| 利润边界 | 当前和拟议策略是否满足项目净利润、毛利润和成本利润率要求 | 正式基准、最新动态和方案后预测的财务确认版本 |
| 专项任务 | 政府沟通、配套、换地、精装等任务是否形成销售或执行约束 | 正式来源、目标、节点、进展、阻碍、责任和支持事项 |

## 前期得失复盘

对每个阶段形成四列：

| 事实 | 当时为何有效/无效 | 现在是否仍成立 | 对下一步意味着什么 |
| --- | --- | --- | --- |

特别区分：

- 开盘热度自然回落与真实策略失效。
- 好卖房源消耗后的库存难度上升与团队转化下降。
- 市场整体下滑与本项目相对份额下降。
- 渠道客户质量下降与案场承接能力不足。

## 因果验证

每个候选原因记录：

```yaml
candidate_cause:
  symptom: null
  proposed_by: data-analysis | user | manager | frontline
  provider_role: null
  observed_context: null
  judgment_rationale: null
  evidence_for: []
  evidence_against: []
  affected_funnel_stage: null
  affected_customer_or_inventory: []
  timing_match: false
  controllability: high | medium | low
  confidence: high | medium | low
  validation_action: null
```

优先使用：

1. 时间一致性：原因先于结果发生。
2. 结构差异：受影响与未受影响客户、房源、渠道存在可解释差异。
3. 对照证据：市场或竞品没有同样下降，或同类项目表现不同。
4. 客户证据：去重客户底表、访谈和未成交原因支持。
5. 小范围实验：修复某因素后领先指标改善。

用户、项目负责人、销售经理和一线人员可以直接提出、补充或修正候选原因及主因果链。对于客户情绪、团队状态、真实执行、合作关系和现场氛围等非纸面因素，人的直接感知是重要输入。记录提出人、角色、具体观察、判断理由和置信度；不因缺少系统记录直接排除，也不把无来源的意见当作已验证事实。

人的判断与数据相互印证时提高置信度；发生冲突时保留两种解释，优先检查数据口径、覆盖范围和未记录事件。必要时可先按专业判断安排低成本、可逆的验证动作，再根据结果确认或调整主因。

允许十多个因素共同作用，但管理结论应归并为一至三条主因果链，例如：

`竞品实景升级 → 本案价值证据不足 → 传播仍讲抽象品牌 → 客户复访下降 → 来访成交转化走弱`。

其余因素标记为放大因素、约束或待验证项，不强行全部归为根因。
