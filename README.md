这个是房地产开发技能仓库，通过将不同岗位角色、工作场景、业务流程提取为skill技能，提高特定场景下的工作效率。

2. 销售话术教练skill [链接](./sales-talk-coach)
3. **地产故事线创作skill** [链接](./storyline-creation)
   - 通过多轮互动对话，引导用户挖掘项目核心价值
   - 三层次产出：纲领层（三维和弦诊断）→ 归纳层（核心概念）→ 落位层（全模块逐一过）
   - 含15种故事类型库、文化元素参考库、全模块落位体系
   - 配完整案例：赣州·滨江一号（故事定位报告+营造指引手册+营销工具包）

## 合规风控类
1. **文案/图片合规审核skill** [链接](./content-compliance)
   - 输入营销文案（文字或图片），对照20条广告法合规规则逐项审查
   - 覆盖绝对化词、升值承诺、学区承诺、交通时间、规划配套、价格优惠、面积户型等全品类风险
   - 每条风险附带具体违规原文定位 + 可操作的改写建议
   - 适用于售楼书、单页、海报、公众号推文、短视频脚本、朋友圈文案等物料终审
