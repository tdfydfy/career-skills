# 完整训练样例

本文件用于校准行为，不是固定答案。运行时应根据用户实际回答、当前项目资料和隐藏客户卡片动态变化。

## 样例一：项目说辞考核

用户：

```text
使用 $sales-talk-coach，做项目说辞考核，我讲澜庭序整体沙盘。
```

教练：

```text
已进入项目说辞考核。本轮按默认项目澜庭序。我会像销售经理一样提问。
请你先用 2 分钟概括这个项目最核心的 3 到 5 个优势。
```

销售：

```text
澜庭序主要是中建系品质，位置在东部新城，离地铁不远，户型有 89 到 143 平，园林也比较好，适合改善客户。
```

教练追问：

```text
你刚才讲到了区位、产品和园林，但都比较概括。先追问两个点：
1. 这个项目的低密和归家礼序，具体能转成客户什么居住利益？
2. 89、108、128、143 平分别更适合哪类家庭？不要只报面积。
```

销售：

```text
低密就是楼间距更舒服，回家动线更有仪式感。89 适合婚房，108 适合一孩家庭，128 适合二孩，143 适合三代同堂。
```

教练继续追问：

```text
方向对，但 143 平不一定是“三代同堂”的唯一答案，128 平也能承接三代短期照护。继续补两个模块：
1. 园林的“一轴、两庭、六境”分别怎么讲成老人、孩子和家庭活动场景？
2. 如果客户问“学区能不能保证”，你怎么合规回答？
```

销售：

```text
园林主要有归家轴线、儿童活动和老人活动区，孩子可以玩，老人可以散步。学区不能保证，要以政府政策为准，我们可以帮客户看公开资料。
```

教练评分节选：

```text
### 项目说辞考核报告

总分：72/100

分项评分：
- 价值点覆盖完整度：27/40
- 价值转化能力：14/20
- 结构与表达清晰度：11/15
- 准确性与合规性：14/15
- 记忆点与可复制性：6/10

已覆盖：
- 项目定位、东部新城板块、89-143 平产品矩阵、低密、园林、学区合规边界。

遗漏：
- 好房子口径中的安全、舒适、绿色、智慧、好运维。
- 竞品江岸云邸、都会峰境、东宸学府的客观取舍。
- 价格区间和首付/月供拆解方法。

讲虚：
- “园林比较好”缺少一轴、两庭、六境和具体生活场景。
- “中建系品质”没有转成客户能感知的材料、建造、运维和物业响应。

优秀改写方向：
澜庭序不是靠单一卖点打客户，而是把低密社区、家庭园林、好房子标准和 89-143 平产品矩阵组合起来，解决婚房、改善和三代照护家庭长期居住的问题。它不是地铁口项目，学区也不能承诺，所以销售要主动承认边界，再把客户拉回预算、通勤、孩子、老人和长期居住体验的排序。
```

## 样例二：客户接待对练

内部隐藏卡片摘要，运行时不要展示给销售：

```yaml
visible_info:
  visit_count: 首访
  visitor_count: 2
  visible_gender_age: 一对 30 岁左右夫妻
  clothing_and_items: 男士拿着车钥匙，女士一直看手机收藏的户型图
  temperament_state: 女士主动，男士谨慎
  visit_time: 周六下午
  current_event: 刚从江岸云邸看完过来
hidden_profile:
  family_structure: 已婚无孩，计划两年内要孩子，父母可能偶尔帮带
  direct_reason: 婚后改善和未来孩子空间
  deep_motivation: 女士希望一步到位，男士担心月供压力
budget:
  total_price_range: 300 万以内更舒服，最多可上探到 330 万
  down_payment_capacity: 90-100 万
  monthly_payment_tolerance: 1.1 万以内
decision_chain:
  main_decider: 夫妻共同决策
  payer: 夫妻为主，女方父母可小额支持
  black_white_roles: 男士黑脸控预算，女士白脸看品质
needs:
  target_units: 108 平优先，纠结是否上 128 平
objections:
  primary_objection: 价格比江岸云邸高一点且离地铁远
reveal_rules:
  easy_to_reveal: 刚看过竞品、想看 108 平
  reveal_after_trust: 首付和月供上限、父母支持情况
  reveal_only_if_asked: 谁拍板、是否计划要孩子
scoring_focus:
  training_theme: 竞品对比、预算拆解、夫妻决策链
```

开场：

```text
已进入客户接待对练。本轮按默认项目澜庭序，我将扮演客户，你直接回复我即可。

现场可观察信息：
- 本次是首访，一共来了 2 位客户。
- 看起来是一对 30 岁左右夫妻，女士更主动，男士比较谨慎。
- 女士手机里打开着户型图收藏页，男士手里拿着车钥匙。
- 周六下午到访，进门时提到刚从江岸云邸过来。

客户：你们这边 108 平还有吗？我们刚看完江岸云邸，想顺便对比一下。
```

销售：

```text
有的。江岸云邸您刚看完，肯定印象还比较新。您方便说下他们那边让您比较满意的是交通、价格，还是户型？
```

客户：

```text
他们离地铁近一点，价格好像也低一些。不过户型我老婆觉得一般，所以想看看你们 108 平。
```

销售：

```text
明白，那我先不急着讲我们好。您二位这次更核心的是通勤便利，还是未来住得舒服一点？如果两个都要平衡，我可以按 108 平帮您把地铁、总价、户型和后期居住列一张对比。
```

客户：

```text
我们肯定也在意通勤，但以后可能要小孩，所以户型也不能太将就。主要还是怕月供太高。
```

销售：

```text
那今天先把预算拆清楚会更实际。您希望首付控制在多少、月供大概别超过多少？我按这个边界给您看 108 平，不合适就不硬推。
```

客户：

```text
首付差不多 90 多万吧，月供最好一万出头，太高了我压力会比较大。
```

销售：

```text
这个边界很清楚。那 108 平会比 128 平更稳一点，我先带您看 108 平，同时把一套低总价和一套楼层更好的房源列出来。看完我们再判断有没有必要上探。
```

客户：

```text
可以，先看 108 平。128 平我们也想了解一下，但如果压力太大就算了。
```

用户：

```text
结束，复盘。
```

复盘节选：

```text
### 销售话术对练评估

总分：84/100

亮点：
- 没有直接贬低江岸云邸，先问客户满意点，竞品处理合规。
- 及时识别“女士看户型、男士控预算”的夫妻决策分工。
- 用首付和月供边界筛选户型，避免硬推 128 平。

主要问题：
- 可以更早确认是否计划要孩子，以及父母是否会参与出资或居住。
- 对澜庭序 108 平的价值转化还不够具体，缺少双卫、收纳、长期居住弹性的表达。

改进话术：
“既然您提到未来要孩子，我建议 108 平重点看三件事：双卫能不能解决早晚高峰、收纳够不够、父母偶尔来帮忙有没有弹性。我们不先上 128，是因为您月供边界很清楚，先把住得舒服和压力可控同时守住。”

下一轮建议：
继续训练“夫妻共同到访时如何识别黑白脸和出资人”，重点问出谁最终拍板、父母是否参与、复访时需要谁到场。
```
