# 首开价格报告财务口径

## 模型关系

`全投资计息`是项目统一财务测算整体，“全计息”和“全投资”均为简称。报告中只维护一套全投资计息模型，不把两种简称拆成不同利润体系。

住宅、商业和车位均纳入同一个项目利润框架。先分业态展示售价、货值和经营结果，再汇总到项目整盘；不得把分业态与整盘数据跨范围拼接。

## 财务指标

全投资计息净利润、成本利润率、毛利率、净利润率、IRR和车位成本利润由财务提供。使用时记录数值、单位、测算范围、模型版本、基准日、财务提供人和日期。

财务未提供专门公式时：

- 按指标字面含义撰写比较结论，不因简称不同建立两套指标。
- 原样保留财务提供值；没有数值则写 `待财务提供`。
- 需要临时解释或复算时标记 `字面口径/待财务复核`，不得称为企业正式公式。
- 不从利润率倒推成本，不跨版本拼接利润、现金流和货值。

## 启动会与首开价格评审会

- 启动会：拿地后确定项目整体策略、整盘及分业态价格和核心经营指标。
- 首开价格评审会：首次开盘前确定首开范围、首开价格和开盘量价目标，通常距启动会三至六个月。
- 比较原则：反映期间经济技术指标和市场变化；允许有依据的量价偏差，但原则上尽量保持或超越启动会指标。未达到时解释原因、影响和修复路径。

## 回正定义

- 土地款回正：累计销售回款达到或超过已投入土地款金额的最早时点。
- 现金流回正：累计销售回款覆盖土地、工程、设计、营销及其他纳入项目现金流投入的最早时点，通常晚于土地款回正。

项目测算时由财务确认“其他费用”范围、采用计划还是实际回款，以及回正后再次转负的处理规则。

## 精装修剔除

剔除精装修后售价 = 带装修售价 - 精装修成本。若按单价计算，售价和精装修成本必须采用同一建筑面积单位；精装修成本由成本或财务提供。

## 价格边界

| 价格 | 正式含义 |
| --- | --- |
| 启动会批复价 | 启动会确定的整盘均价和各业态均价 |
| 首开申请价格 | 本次首开范围整体均价和各业态均价 |
| 房号底价 | 经集团审批备案的一房一价表，原则上不可低于对应价格销售 |
| 表价 | 对客户公开展示的房源价格 |
| 净成交价 | 表价扣除已批准优惠和折扣后的实际成交价格，应高于或等于房号底价 |
| 整盘预计实现价 | 按首开及后续批次价格、货量和去化假设形成的整盘预测均价 |

## 车位敏感性

营销侧向财务提供车位分类、可售数量、成交价格、去化率和车住联动情景。财务单独提供各情景下的车位成本利润、净利润、车位货值占净利润比重和成本利润率；报告不得自行替代财务测算。
