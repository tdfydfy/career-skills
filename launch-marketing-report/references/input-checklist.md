# 首开报告输入清单

## P0：没有就不能下核心结论

### 项目与目标

- 集团、地区和项目对规模、利润、现金流、库存、品牌或标杆的优先顺序。
- 启动会、年度经营计划和专项会议批复的目标、红线、资源承诺及偏差容忍度。
- 城市、板块、区位、项目定位、物业类型、产品规模和首开范围。
- 首开或加推时间、目标套数、金额、价格、回款、利润或标杆任务。
- 取证、售楼处、示范区、样板间、实景和工程节点。
- 组织层级、项目负责人、审批权限和跨专业约束。

### 货量与价格

- 楼栋、楼层、户型、面积、位置、景观、交付、套数和货值。
- 可售、待推、已售、预留和不可售状态。
- 表价、批复目标价、当前净价、底价、折扣和赠送资源。
- 价格会、财务和成本已确认或待确认的事项。

### 客户与客储

- 客户来源、区域、家庭、动机、预算、面积、总价、竞品和抗性。
- 首访、复访、有效客户、认筹、意向房源和决策链。
- 探索性、验证性或确定性盘点阶段。
- 有效客储标准和客户预测窗口。

### 市场与竞品

- 近十二个月市场供应、成交、均价和去化周期。
- 当前和未来竞品的产品、价格、货量、流速、展示、渠道和动作。
- 新房、二手房、土地、政策和板块心理距离。

### 决策与验证

- 本报告需要领导批准、知悉、协调或授权的事项。
- 已经否决或明确不做的客群、房源、价格、渠道、展示和费用方案。
- 市场、客户、价格、展示及渠道假设的验证节点、责任人和失效条件。

## P1：影响策略质量

- 产品价值、故事线、客户价值转换和竞品取舍。
- 媒体、渠道、活动、展示和销售的历史效率。
- 线索、来访、有效客户、认筹、成交、签约和回款各层转化基准及来源。
- 团队岗位、编制、能力、排班、训练和激励。
- 签约、按揭、回款、费用和现金流计划。
- 传播主题、图片、视频、软文和销售物料资源。

## 输入完整度

### A级

核心输入有来源、日期和责任人；公司经营任务、价格货量、客户客储、财务边界和首开节点可以相互验证；历史转化或验证计划能够支持目标反推。

### B级

有目标和项目基础资料，但经营优先级、客户、财务、竞品、转化或展示有缺口。可以输出带假设、情景和验证动作的方案，不给不可追溯的精确承诺。

### C级

只有项目名称、阶段或模糊目标。只输出资料清单、报告骨架和需要决策的问题。

## 首轮追问优先级

1. 公司经营优先级、启动会基准、首开范围、时间、目标和主要决策人。
2. 可售及待推货量、当前价格和财务边界。
3. 有效客储、客户价格预期、转化基准和首开盘点阶段。
4. 当前直接竞品、未来供应和最强竞争动作。
5. 展示、取证、费用和销售组织是否满足节点。
