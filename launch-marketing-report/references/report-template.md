# 项目首开型营销策略报告模板

## 前置：管理摘要与策略命题

1. 公司经营意图、项目战略任务和不能突破的边界。
2. 一至三个核心矛盾和结构性机会。
3. 一句话策略命题、推荐推售模式及不做事项。
4. 首开时间、范围、量价、客储、回款和费用目标。
5. 基准/进取/谨慎方案、失效条件和待决策事项。
6. 策略推导表：证据→判断→含义→选择→动作→指标→预算。

## 第一部分：项目基本情况

### 1. 整盘货量与户型

- 住宅、商业、车位、储藏室等分业态套数、面积、批复均价和货值。
- 户型面积、格局、套数、面积和占比。
- 启动会、当前规划及最新经营版本差异。

### 2. 推售计划

- 各批次楼栋、产品、套数、面积、货值、时间、销售期和战略作用。
- 分年度销售金额、去化率、价格和回款安排。
- 推售顺序与市场窗口、客储、展示和后续货量的关系。

### 3. 展示与工程节点

- 一展、二展、三展、取证和开盘时间及开放范围。
- 每项展示解决的客户抗性、证明的价值和承接动作。
- 延期、替代展示和非交付标准风险。

### 4. 首开目标铺排

- 首开供应、销售套数/金额/去化、认筹、有效客户、来访和线索目标。
- 分户型、分渠道和分时间目标。
- 解筹率、到访转筹率、线索到访率及依据。

本部分必须回答：公司要求项目完成什么，现有货量、节点和资源是否支持。

## 第二部分：市场竞品情况

### 1. 城市与板块市场

- 供销价走势、广义/狭义库存、去化周期、土地和政策。
- 面积段、总价段、产品和板块结构机会。
- 基准、进取和谨慎市场情景。

### 2. 竞争格局

- 主力在售、持销、待售和替代竞品分布。
- 产品、货量、价格、流速、展示、配置、客群和渠道动作。
- 分户型直接竞争和客户分流判断。

### 3. 市场及竞品小结

形成四项结论：市场容量、合理流速、价格位置、开盘窗口。每项说明对本案推售、价格、价值、客储或节点意味着什么。

## 第三部分：价值策划及推广策略

### 1. 整体营销节点

按入市、起势、强蓄、认筹、升筹、开盘和持销铺排客户任务、释放信息、展示证据、活动、媒体和转化承接。

### 2. 客户痛点与价值体系

按“客户痛点→土地/配套/产品/品牌事实→竞品差异→客户利益→证明方式”组织核心价值。明确主价值、辅助价值和暂不传播内容。

### 3. 故事线与内容矩阵

- 核心主张、价值支柱、事实证据和话术转换。
- 主形象、软文、短视频、直播、户外、案场和销售物料任务。
- 每阶段内容目的：认知、解释、留资、邀约、认筹或成交。

### 4. 分阶段推广和活动

每阶段列目标客户、客户任务、主题、内容、媒体、活动、展示、销售承接、预算和指标。案例创意不得替代策略目的。

### 5. 商业、车位及其他业态

分别明确业态货量、客户、价格、节点、招商/销售动作及与住宅的真实联动，不做未经批准的捆绑或增值承诺。

车位原则上从首开阶段同步销售：分别设置住宅和车位目标、车住销售比、客户意向、组合权益及人员考核。组合政策必须客户自愿，住宅优惠后不得低于房号底价，并由财务确认车位利润与项目整体影响。

本部分必须回答：用什么可验证价值改变目标客户的认知和选择，在哪个节点促成什么行为。

## 第四部分：客储策略

### 1. 客储目标与来源分解

- 从成交目标反推认筹、有效客户、来访和线索。
- 分自然来访、自拓、新媒体、活动、分销/全民经纪、老带新、企拓等渠道。
- 说明历史转化、成本和本期调整依据。

### 2. 组织与过程管理

- 自渠/销售组织、岗位、编制、责任、排班和协同。
- 周/月动作量、有效客户验收、CRM录入、抽查和盘客机制。
- 积分、激励和淘汰机制需符合劳动、预算和权限规则。

### 3. 分渠道策略

按需选择：拓销一体、新媒体、资源整合、企拓、大客户、老带新、CALL客、地推、全员营销、合作单位和户外。每个渠道必须写客户池、动作、漏斗目标、成本、责任人和退出条件。

### 4. 销售转化承接

- 首访、复访、盘客、ABCD评级、MAN、房源落位和价格验证。
- 说辞、训练、认筹、升筹、选房、签约和回款。
- 客储不足、结构错配和承价不足时的调整路径。

本部分必须回答：客户从哪里来，谁执行，如何从线索转成成交，怎样证明渠道有效。

## 第五部分：费用预算

### 1. 预算总表

按广告、制作、活动、客户拓展、人员、销售管理、代理、卖场和劳务等正式科目列预算、占比、说明和审批状态。

### 2. 阶段与动作预算

把全年预算分到入市、展示、认筹、开盘等首开技术节点、持销阶段及重点动作，区分预算、承诺、确认和支付。

### 3. 预算与目标闭合

- 合约目标、营销费率及分子分母。
- 单线索、来访、有效客户、认筹和成交成本。
- 各渠道和活动的领先/结果指标、复盘时间和停止规则。
- 基准、谨慎情景以及预备费使用条件。

本部分必须回答：为什么这些钱应花在这些动作上，以及达不到什么指标时停止或调整。

## 附件

策略推导表、项目事实包、市场与竞品底表、客户客储底表、货量价格表、展示节点、价值证据、内容排期、渠道漏斗、活动任务书、组织RACI、预算明细、风险台账和审批意见。
