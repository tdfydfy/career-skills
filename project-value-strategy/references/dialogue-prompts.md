# 交互提问与降级策略

## 提问顺序

每轮从当前最大不确定性出发，通常按以下顺序推进：

1. 项目是什么：城市/板块、阶段、产品、核心资源。
2. 卖给谁：家庭结构、置业动机、预算/价格带、决策周期、当前抗性。
3. 凭什么买：已证实的区位、产品、服务和展示证据。
4. 为什么选它：主要竞品、客户比较维度、项目不能输的点。
5. 如何让客户相信：现场体验、物料、销售动作和传播渠道。
6. 如何推进成交：节点、房源、转化目标、复盘指标。

## 选择题示例

- 目前更想解决：A 项目定位不清 / B 卖点太散 / C 现场不会讲 / D 传播没有主线？
- 客户买单更可能来自：A 地段效率 / B 景观稀缺 / C 产品改善 / D 服务与身份？
- 现阶段最有把握的证据是：A 已兑现现场 / B 图纸和标准 / C 客户反馈 / D 还在设想？
- 你希望本轮先拿到：A 一页清单 / B 完整价值体系 / C 落地推进表 / D 传播排期？

## 交互规则

- 每轮先复述已知信息，再问 1 组问题，说明这些答案会影响哪个判断。
- 用户只回答一部分时，先基于已知内容推进，不强迫补齐全部字段。
- 用户说“不知道/没有”时，提供一个暂定选项、一个保守选项和一个需要调研的选项。
- 连续两轮无法补证时，进入“假设版”：明确假设、降低承诺强度、给出验证任务。
- 不要重复已经确认的问题；把新信息写回项目底盘。

## 信息不足时的降级输出

```text
当前可以确定：……
暂定判断（尚需验证）：……
暂不建议对外传播：……
最小补证动作：……（谁在何时用什么材料验证）
在补证前可先做：……（低风险的现场/内容动作）
```

## 收敛信号

当以下条件同时满足时可以交付：

- 用户确认了一个总核心价值或明确接受两套候选路径；
- 一级价值均有至少一个 A/B 级证据，或明确列入补证任务；
- 关键落地模块和传播阶段已有负责人/下一步动作；
- 用户知道哪些内容不能直接作为对外承诺。
