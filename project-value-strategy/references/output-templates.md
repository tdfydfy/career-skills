## 深度版：策略报告

```markdown
# [项目名]项目价值策略报告

## 一、执行摘要
结论、选择理由、当前最大机会与风险。

## 二、项目底盘
区位 / 产品 / 资源 / 客群 / 价格带 / 阶段 / 竞品 / 已有展示。

## 三、价值诊断
### 1. 五维扫描
### 2. 客户任务与购买障碍
### 3. 竞品比较维度
### 4. 价值优先级与证据缺口

## 四、价值体系
总核心价值：
一级价值 A/B/C：
每个一级价值包含证明点、适配客群、表达边界和待核实项。

## 五、落地执行
规划与城市界面 / 归家与公区 / 建筑与户型 / 服务与交付 / 销售现场。
每项写动作、责任方、节点、验收、成本/风险。

## 六、传播与转化
主叙事 / 支叙事 / 客群分层 / 阶段内容 / 渠道 / CTA / 排期 / 指标 / 复盘机制。

## 七、30秒与3分钟讲法
### 30秒
### 3分钟

## 八、决策事项
需要用户或项目团队确认的 1~3 项。
```

## 单项交付

用户只需要价值点清单、落地表、传播排期或销售讲法时，输出对应部分，但仍保留证据等级和待核实项，避免脱离项目事实。
