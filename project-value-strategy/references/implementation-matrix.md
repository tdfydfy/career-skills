# 价值点落地矩阵

## 使用方法

从“客户要的结果”倒推“客户在哪里感知”，再指定动作和验收方式。不要为每个空间硬套一个口号；同一价值点可以跨多个模块重复出现，但每次都要有不同的体验证据。

| 落地层 | 重点模块 | 可落地动作 | 验收问题 |
|---------|----------|------------|----------|
| 城市界面 | 城市道路、围墙、大门、展示面 | 入口识别、夜间界面、首屏信息、城市资源导视 | 路人/首次到访者能否在 10 秒内理解项目的主价值？ |
| 归家体验 | 车行、人行、地库、单元入口、电梯厅 | 动线、遮雨、标识、照明、气味、收纳、老人儿童友好 | 从下车到入户是否连续、清晰、舒适？ |
| 公区体验 | 园林、会所、泳池、儿童区、架空层 | 场景配置、动静分区、可运营设施、季节体验 | 客户能否实际使用，而不是只看到效果图？ |
| 建筑产品 | 立面、窗墙、阳台、层高、设备、交付标准 | 视野、采光、隔音、收纳、材质、维护方案 | 价值是否有图纸、样板间或实测支持？ |
| 户型生活 | 玄关、LDK、主卧、卫生间、阳台/院子 | 家庭动线、功能弹性、家具尺度、适老/儿童细节 | 不同家庭成员是否都能说出具体收益？ |
| 服务信任 | 物业、交付、工程透明、售后、社群 | 服务流程、可视化标准、体验官、交付承诺管理 | 客户如何在购买前验证长期兑现能力？ |
| 销售现场 | 接待台、沙盘、样板间、洽谈区 | 讲解顺序、证据物料、体验任务、异议回应 | 销售是否能用 30 秒和 3 分钟两种版本讲清？ |

## 价值点执行卡

```text
价值点：
客户结果：
事实证据：
现场/产品落位：
销售动作：开场 / 讲解 / 异议 / 复访
内容动作：图片 / 视频 / 文章 / 直播 / 口碑
责任方：设计 / 工程 / 物业 / 策划 / 销售 / 渠道
完成节点：
验收指标：
风险、成本与待核实：
```

## 三种落地深度

- **基础版**：说明价值点、证明材料、现场讲法和一条传播表达，适合前期讨论。
- **执行版**：补充负责人、节点、物料、预算级别、验收和备选方案，适合项目周会推进。
- **体验版**：把到访动线写成任务脚本，标明客户在每个节点看到什么、听到什么、做什么，适合开放前联调。

## 约束

- 规划、配套、学区、交通、交付和物业服务按实际状态写“已兑现/建设中/规划中/待确认”。
- 设计建议要考虑成本、维护、消防、无障碍、儿童安全和运营能力；不越权替代专业设计审查。
- 不能通过增加命名、装置或包装制造不存在的稀缺性。
