## 幻灯片2：管理摘要

**结论：项目不是单纯“市场变差”或“价格高”，而是竞品冲击、价值展示失效、团队承接中断和165㎡结构性库存三条因果链叠加。建议先用两周修复执行、价值与展示，四至八周结合加推、权益和房车同售恢复流速；未达到价格触发条件前不做全盘普降。**

| 决策项 | 建议 |
| --- | --- |
| 异常 | 项目到访较4月下降50%，市场同期仅下降12%；来访成交率由9.23%降至6.15% |
| 主因果链 | 竞品+展示传播；团队+执行；165㎡产品、总价和展示错配 |
| 八周目标 | 600组到访、60套住宅、1.35亿元、45个车位 |
| 价格态度 | 先修复非价格因素；四周后仍低于8%且价格流失占比超50%才启动房号级调价 |
| 权益 | 165㎡可选封窗或家电包，单套资源成本不超过3万元 |
| 房车同售 | 客户自愿组合，住宅额外优惠2万元但不低于房号底价；车住目标比0.75 |
| 费用 | 八周新增180万元；整盘预测费率仍控制2.5% |

## 幻灯片4：前期销售得失

**有效经验：** 首开期115/135㎡、完整价格口径和集中展示能够支持约9%-10%来访成交。
**失效经验：** 持销期仍沿用“智慧奢居”抽象传播、按渠道带看量考核和首开期团队节奏，在竞品实景入市、剩余库存变难后不再有效。

| 前期做法 | 当时有效原因 | 当前变化 | 下一步 |
| --- | --- | --- | --- |
| 集中推广智慧科技 | 首开有新鲜度 | 客户当前更关心总价、空间、兑现 | 重构价值主张 |
| 全产品统一销售 | 首开货量均衡 | 165㎡占库存39.5%且总价高 | 分产品策略 |
| 分销按带看量 | 首开流量有效 | 高佣竞品吸走优质客户 | 改为有效客户验收 |
| 统一团队动作 | 经理稳定、12人在岗 | 经理更换、缩编、CRM缺失 | 恢复管理基本盘 |

## 幻灯片6：十五项候选因素

外部：市场成交下降、一级竞品入市、竞品低总价、竞品高佣分销、客户观望增强。
内部：165㎡库存偏重、样板间缺失、价值主张错位、售楼处老化、团队缩编、经理更换、跟进不及时、CRM缺失、渠道质量失控、新媒体承接慢。

这些因素不是十五个并列根因。经时间、结构、客户和对照证据验证后，归并为三条主因果链和一个放大因素。

## 幻灯片7：主因果链一——竞争与价值证据

`竞品低总价+完整示范区+高佣 → 优质渠道和改善客户转移 → 本案仍讲抽象科技且展示老化 → 到访份额8.5%降至5.1% → 复访和成交下降`

证据：项目到访下降50%，明显高于市场下降12%；120组流失样本中40组等待竞品、28组认为展示或价值证据不足。
反证：项目车位配比和生活圈距离仍有优势，说明不是项目整体失去竞争力。
置信度：高。

---

## 幻灯片8：主因果链二——团队与执行

`经理更换+团队缩编 → 盘客中断、跟进及时率62%、CRM完整率82% → 渠道和新媒体客户承接不一致 → 来访成交率由9.23%降至6.15%`

销售个人转化率分布2%-12%，证明相同市场和价格下执行差异显著。先修复团队和执行，可以用较低风险验证约3个百分点的转化损失。

## 幻灯片11：两周止跌动作

1. 恢复每日盘客和销售经理逐客审核，48小时跟进及时率由62%提升至95%，CRM完整率由82%提升至98%。
2. 传播从“智慧奢居”切换为总价、空间、交付可信和车位便利，复访预约率目标30%。
3. 完成165㎡临时实体展示和一房一客复盘，建立40组有效客户池。
4. 渠道从带看量考核改为有效客户验收，新媒体线索24小时内分配。

两周未完成执行标准，不得把转化不改善归因于价格。

## 幻灯片13：权益替代直接降价

165㎡客户可自愿选择封窗或家电权益包，单套资源成本不超过3万元。权益必须经客户需求验证、财务折算、合同明确和交付确认。

选择权益而非直接普降的原因：当前价格只是165㎡问题的一部分；展示缺失和团队承接尚未修复；直接降价会同时影响135㎡价格、后续货量和老业主预期。

老业主保护：公开说明新权益的适用房源、期限和成本，不制造虚假原价；上线前完成历史成交客户与投诉风险评估。

## 幻灯片14：加推与价格策略

8月16日拟加推6号楼72套：

- 115㎡36套：保流速，控制总价，承接最大客户池。
- 135㎡36套：立标杆，以新楼栋、展示和价值证明价格。
- 165㎡：不新增供应，先去化现有64套。

价格触发条件：完成四周执行与展示修复后，项目来访成交仍低于8%，且135/165㎡未成交客户中超过50%明确因净价差距放弃，才启动房号级结构性调价审批。即使触发，也不做全盘普降。

## 幻灯片15：房车同售

**结论：住宅已售158套但车位仅售62个，当前车住比0.39；未来八周目标住宅60套、车位45个，车住比0.75。**

组合政策：客户自愿同时购买指定车位，可获得住宅额外优惠2万元，优惠后不得低于房号底价；住宅和车位价格、合同及权属分别披露。

销售考核：住宅70%、车位20%、合规与签约回款10%。不强制捆绑，不因客户只买住宅而隐瞒正常可售房源。

## 幻灯片18：会议决策事项

1. 批准180万元八周改善预算及动作间动态调配，整盘费率仍控制2.5%。
2. 批准165㎡封窗/家电两类可选权益包，单套资源成本不超过3万元。
3. 批准客户自愿房车组合，住宅额外优惠2万元且优惠后不低于房号底价。
4. 确认四周价格触发门槛，未触发前不进行全盘普降。
5. 确认8月16日加推6号楼，115㎡保流速、135㎡立标杆，不新增165㎡供应。
6. 要求销售、策划、渠道、工程、财务和法务按两周、四周、八周节点复盘关闭。
