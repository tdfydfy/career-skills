# 虚拟持销专题诊断前测审查

## 结论

状态：`通过异常虚拟案例前测`。

案例证明技能能够保留十五项候选因素，同时通过时间、结构、客户和对照证据归并为三条主因果链，而不是笼统归因市场或直接建议降价。

## 检查结果

| 检查项 | 结果 | 说明 |
| --- | --- | --- |
| 问题界定 | 通过 | 到访下降50%、转化降至6.15%、165㎡库存和车位积压均有时间与范围 |
| 前期得失 | 通过 | 区分首开期有效做法和持销期失效条件 |
| 多因诊断 | 通过 | 5项外部、10项内部因素保留，归并为3条主链和1个放大因素 |
| 因果证据 | 通过 | 市场仅降12%而项目到访降50%，客户样本、时间线和人员差异共同支持 |
| 非价格优先 | 通过 | 两周先修复执行、价值、展示与渠道承接 |
| 重大改革门槛 | 通过 | 四周低于8%且价格流失超过50%才启动房号级调价 |
| 权益方案 | 通过 | 165㎡权益有客户、成本、合同、交付和老业主边界 |
| 加推策略 | 通过 | 115㎡保流速、135㎡立标杆、不新增165㎡ |
| 房车同售 | 通过 | 车住比0.39提升至目标0.75，客户自愿且住宅不低于底价 |
| 费用 | 通过 | 改善预算包含在剩余2,290万元内，整盘费率控制2.5% |

## 关键复算

- 已推住宅：`158已售 + 162可售 = 320套`。
- 整盘住宅：`320已推 + 280未推 = 600套`。
- 已推库存：`40 + 58 + 64 = 162套`。
- 客户流失样本：`40 + 28 + 18 + 14 + 10 + 6 + 4 = 120组`。
- 当前车住比：`62 ÷ 158 ≈ 0.3924`。
- 整盘营销费率：`3,550万元 ÷ 14.20亿元 = 2.5%`。
- 剩余费用：`3,550 - 1,260 = 2,290万元`。
