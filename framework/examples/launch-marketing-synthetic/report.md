## 幻灯片13：首开前六天传播策略

**结论：传播从扩大曝光转为降低决策不确定性。**

1. `实景证据`：以样板间、示范区和归家动线的真实画面回答兑现问题。
2. `房号价值`：按105/125/132/168㎡拆分总价、楼层、景观和选择逻辑。
3. `规则透明`：统一首开时间、选房规则、付款资料和价格口径。
4. `客户承接`：所有内容进入专属销售，24小时内完成复访或房号落位。

内容指标使用复访预约、资料齐备、决策人到场和房号落位，不再只看播放量。

| 环节 | 责任 | 验收标准 |
| --- | --- | --- |
| 签到与资料核验 | 销售内业 | 客户、认筹、付款资料一致 |
| 房源及价格公示 | 销售经理/财务 | 表价、优惠、底价和销控一致 |
| 摇号与选房 | 开盘执行组 | 顺序留痕、房源实时销控 |
| 付款与签约 | 财务/签约 | 认购后7日内签约计划明确 |
| 未成交承接 | 置业顾问 | 当日记录原因、次选房号和跟进节点 |

## 幻灯片19：销售组织与一房一客

1. 每日18:00前更新客户唯一编号、评级、第一/第二房号、承价、决策人、资金和未解决问题。
2. A类检查付款资料和首选/备选房号；B类只保留一至两个明确障碍并配置责任人。
3. 168㎡客户由销售经理逐组复核，确保决策人开盘到场和付款路径可执行。
4. C类保留后续触达，D类不占用首开重点资源；B/C加减级只表示类内相对强弱。
5. 开盘当晚复盘未成交原因，区分价格、房源、付款、竞品、家庭决策和流程问题。
