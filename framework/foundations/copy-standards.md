# 房地产文案标准

状态：`draft`

## 目的

统一房地产营销文字的事实基础、信息结构、品牌语气、渠道适配和审核流程。文案负责把真实价值翻译给目标客户，不负责创造项目事实。

## 写作前提

每次写作先建立 `content-brief`，至少明确：

- 业务目的和期望客户动作。
- 目标客户及其当前认知阶段。
- 发布渠道、载体、篇幅和截止时间。
- 一个核心信息和至多三个支撑信息。
- 可使用事实、不可使用内容和必要免责声明。
- 审核人和最终发布版本。

## 内容结构

通用结构为：

```text
客户关切或真实场景
  → 项目事实和价值解释
  → 证据、细节或体验
  → 明确但克制的行动指引
  → 必要限制条件和免责声明
```

不要从空泛形容词起手，也不要把所有卖点塞进一篇内容。

## 表达规则

- 先说事实，再说价值，再说客户意义。
- 使用具体名词和动作，减少“尊贵、极致、封面”等无证据形容词。
- 数据、荣誉、规划、距离和价格注明来源、状态、条件和日期。
- 面积使用“建筑面积约”，户型、交付和展示说明以合同及审批资料为准。
- 竞品对比使用可验证维度，不贬损、不暗示虚假缺陷。
- 不承诺升值、入学、政策、贷款、交付外配置和未批准服务。
- 不虚构热销、房源紧张、客户证言、专家意见和内部消息。

## 渠道适配

- 软文：围绕一个主题形成完整论证，保留证据和客户场景。
- 公众号图文：标题、摘要、首屏、分段、小标题和结尾动作一致。
- 朋友圈：一条只传递一个信息，避免连续堆叠极限词和价格诱导。
- 海报：主标题、核心证据、行动信息和限制条件形成清晰层级。
- 新闻稿：事实优先，区分企业观点与外部数据，不写成硬广堆砌。
- 短视频口播：每句可自然说出，风险提示不能因口播形式省略。
- 销售说辞：口语化、可验证、允许客户追问，未知信息明确待确认。

## 品牌语气

企业品牌词典尚未提供前，默认采用准确、克制、清楚、有温度的表达。不得自行设定高端、年轻、豪宅或网红语气。

## 审核顺序

1. 事实审核：项目、价格、房源、时间和数据是否准确。
2. 业务审核：是否服务当前策略和目标客户。
3. 品牌审核：语气、名称和视觉语言是否一致。
4. 合规审核：调用 `content-compliance`。
5. 发布审核：渠道规格、链接、联系方式和版本是否正确。

## 待企业校准

- 品牌核心词、禁用词、固定称谓和标点规范。
- 不同项目档次及客群的语气差异。
- 各渠道字数、发布频次和审批流程。
- 标准免责声明和项目必备信息模板。
- 历史优秀文案与失败案例。
