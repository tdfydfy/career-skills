# 营销经营指标字典

状态：`draft`

机器可读指标定义见 `../knowledge/metric-baseline-001.yaml`。

## 目的

统一总部、地区、项目及各业务技能使用的指标名称、公式、统计范围和时间口径，避免同一词语在不同报告中代表不同数字。

指标字典定义“怎样计算和解释”。项目状态优先依据年度合约额目标、全年预计实现和剩余完成压力判断，绝对流速和销售质量作为补充，不建立脱离操盘过程的综合健康评分。

## 强制规则

### 1. 每个数字带六项上下文

- 指标ID和正式名称。
- 项目、地区或总部范围。
- 住宅、车位、商业等物业范围。
- 统计开始和结束时间。
- 数据截止时间。
- 数据来源和状态。

缺少上述信息时，只能作为待核实数字，不得直接用于重大经营决策。

### 2. 禁止使用模糊指标名

以下表达不能单独出现在正式成果中：

- “销售额”：应明确毛成交或净销售合约额。
- “成交”：应明确客户数、套数、面积或金额。
- “来访”：应明确首访组数、复访组次或去重到访客户组数。
- “认筹”：应明确认筹客户数或认筹套数。
- “转化率”：应明确线索到访、到访认筹、认筹成交或到访成交。
- “回款率”：应明确到期回款完成率或回款目标完成率。
- “库存”：应明确可售库存、待推售货量、套数、面积或货值。
- “均价”：应明确物业范围、成交状态和建筑面积口径。

### 3. 人、组、次、套不能混用

- 客户以 `customer` 表示自然人或系统客户主体。
- 客户组以 `customer_group` 表示共同购房决策单元。
- 到访行为以 `visit_time` 表示一次到访事件。
- 房源以 `unit` 表示一套可交易单元。

同一客户组多次复访只增加复访组次，不重复增加去重到访客户组数。

### 4. 毛成交和净成交同时保留

认购用于观察现场销售流速；正式合约额以明源正式签约金额为准。签约退房在退房发生周期冲减，不追溯覆盖原合约发生周期，保证历史数据稳定。政府网签作为参考状态另行保留。

### 5. 分母为零时返回空值

分母为零或缺失时，比例返回 `null` 并标记 `not-applicable` 或 `data-missing`，不得返回0，也不得用极小数替代。

## 指标体系

### 目标与完成

- 销售合约额目标、销售套数目标、回款目标、营销费用预算。
- 合约额目标完成率、套数目标完成率、回款目标完成率。
- 年度合约额目标是项目状态判断的核心考核指标；套数用于流速和运营效率参考，不作为核心考核。
- 年度目标按正式批复记录，月度目标保留分解版本和调整记录。月度偏差用于趋势分析，不直接替代年度预计实现判断。
- 后续月均合约额要求 = 年度剩余合约额 ÷ 剩余有效销售月份。
- 合约额完成压力比 = 后续月均合约额要求 ÷ 近三个月月均合约额。原则上低于0.8较理想，超过1.2属于危险信号；中间区间结合供货、价格、市场和政策判断。

### 周度最新销售动态

- 周度“销售”对应认购，最新销售动态按认购加认筹合并观察，同时必须保留两者拆分。
- 新增来访、新增认购与认筹、竞品来访成交及量价动作是周会的核心短周期信息。
- 认筹只反映意向和在手，不具备销售效率考核效力；认购反映当前销售流速；明源签约合约额用于正式考核。

### 月度销售与合约预测

- 预计全月销售额 = 已认购金额 + 现有认筹预计转认购金额 + 月内剩余时间预计新增认购金额。
- 预计全月合约额 = 已签约金额 + 已认购待签金额 + 后续新增认购预计在月内签约金额。
- 上述等式表达预测构成，不代表所有在手金额按100%转化；项目负责人需结合客户成熟度和签约周期判断可实现部分。
- 月初预测以负责人综合判断为主，结合经验、前期趋势、市场、节日节点和项目加推计划；月底预测以认购、认筹、待签等在手数据逐项盘点为主。
- 预测必须注明数据截止日、节日与加推假设以及预计转化范围，事实完成值与预测值分开。

### 客户漏斗

```text
线索
  → 首访
  → 客户结构与意向分析
  → 认筹
  → 认购
  → 明源正式签约
  → 回款
```

漏斗转化必须采用客户队列口径，即追踪同一批客户在观察窗口内的后续结果。不能简单用本月成交客户除以本月来访客户，因为成交客户可能来自以前月份。

日常来访不强制划分有效和无效。纯参加活动且没有看房或购房沟通的客户通常不计入来访，其他到访均计入，再按年龄、家庭、工作、渠道、意向、产品需求和抗性分析。首开客储或专题如使用“有效客户”，必须另行定义用途和条件。

### 客户量质与业绩支撑

- 客户量观察来访、认筹、认购和意向等级数量，以及按周、月、渠道、区域和产品拆分的增减变化。
- 客户质观察来源、年龄、家庭、工作、需求产品、价格预期、成交周期和抗性因素。
- 客储预测同时说明未来数量和质量变化，不能只报当前客户总数。
- 业绩支撑判断应从销售合约额或认购目标、产品均价和成交转化反推所需客户量，再与现有及预计客储比较。
- 客户缺口必须区分“老客户障碍未解决”和“新客户来源不足”，分别形成修复或拓新策略。
- 宏观预测按业绩目标、套均总价和转化率反推所需客户量；微观预测由项目销售经理逐客判断需求、价格、决策和房源匹配后汇总。
- 宏观需求与微观盘点不一致时报告差额和原因，不取简单平均，也不以销售经理主观总数替代逐客依据。

### 销售与价格

- 分别记录认购客户与套数、明源签约客户与套数、签约退房冲减及净销售合约额。
- 净成交均价使用净销售合约额除以净成交合同建筑面积。
- 价格实现率必须在相同房源范围内比较净成交均价和批复目标均价。
- 近期量价分析默认展示近三个月逐月值和滚动值，不只展示累计平均。

### 货量与去化

- 区分可售库存和待推售货量。
- 去化率必须明确分母是累计推售套数、推售货值还是某一批次供应。
- 项目库存去化周期使用项目近期月均净成交。
- 市场去化周期使用城市或板块近期月均市场成交。
- 成交为零或市场结构突变时，去化周期只能作为情景值，不能机械外推。

### 市场量价

- 市场供应和成交同时保留套数与建筑面积，避免产品面积变化造成误判。
- 市场成交额和成交面积使用同一来源计算市场均价。
- 市场成交采用认购、网签还是备案口径必须固定，不能跨月份切换。
- 市场趋势默认观察近十二个月，同时标注当前在售、未来竞品和潜在土地供应。

### 首开和加推

- 记录节点供应套数、有效客储、客储货量比、开盘净成交和开盘去化率。
- 项目首次开盘通常观察首开前三天住宅认购套数；100套以上可作为形成基本开盘规模的经验参考，不替代项目正式合约额和去化目标。
- 有效客储必须有统一判定标准，不等于所有来访或所有认筹。
- 开盘成绩必须注明当日、三日或七日统计窗口。

### 经验测算基准

项目自身历史数据、同类项目校准数据优先。缺少可靠历史数据时，可暂用以下企业经验值反推目标，并标记为 `经验假设`：

| 阶段 | 指标 | 经验测算起点 |
| --- | --- | ---: |
| 持销 | 同批去重到访客户→净成交客户 | 约10% |
| 新开盘 | 同批去重到访客户→有效认筹客户 | 约15% |
| 新开盘 | 有效认筹客户→净成交客户 | 约60% |

新开盘从到访到成交的链式参考约为 `15% × 60% = 9%`。该结果只用于检查漏斗数量级；管理上仍要分别观察到访认筹和认筹成交，因为两个环节对应的策略问题不同。

经验值不是考核红线或承诺值。必须明确客户队列、去重、有效认筹、净成交和观察窗口，并在形成真实数据后滚动替换。

### 签约和回款

- 签约周期为认购日期至明源正式签约日期的自然天数。平均3至7天通常正常，超过7天即提示销售质量不健康，超过14天属于高风险。
- 持销阶段原则上不长期接受超过7天的平均签约周期；特殊原因必须逐单记录和验证。
- 认购退房率和签约退房率原则上均不超过5%；超过5%触发客户底表、付款能力、销售真实性和退房原因核查，但不能仅凭比例认定虚假销售。
- 到期签约率使用“已到签约期限的成交”作为分母。
- 到期回款完成率衡量应收款是否按计划到账。
- 回款目标完成率衡量实际到账是否完成经营任务。
- 实际回款以财务确认到账为准，营销系统口径不得自行替代。

### 营销费用

- 营销费率必须确认费用分子、销售或回款分母以及跨期规则。
- 费用效率至少可观察单线索、单首访、单有效客户和单净成交客户成本。
- 获客费用归因不清时，只报告整体费用效率，不制造渠道级精确结论。
- 整盘累计营销费率可暂按约2.5%作为经验控制基准；首开阶段可适度提高至约3%，但必须铺排后续费用压降，使整盘累计费率回归约2.5%。
- 2.5%和3%均为经验基准，不替代正式预算、费用科目、费率分母、跨期规则和审批权限。

### 组织效率

- 分别记录批复编制、实际在岗和薪酬额度。
- 人均合约额使用周期平均在岗人数，不使用期末单点人数。
- 人均指标只能辅助观察，不替代项目难度、货量和市场条件分析。

### 财务与投资

- 财务和投资指标必须来自同一测算版本，不能混用不同批次收入和成本。
- 毛利润和毛利率的成本范围采用企业财务定义。
- 方案增量利润使用拟议方案减基准方案，不只看单套让利。
- 净现金流、回收期、峰值负现金流和IRR由财务或投资专业确认。
- 营销成果引用这些指标时保留版本、时点和情景名称。

## 比较规则

### 同比和环比

- 同比使用上年同周期，处理春节等移动节日时增加可比周期说明。
- 环比使用紧邻上一完整周期，未完整月份不得直接与完整月份比较。
- 同比、环比必须保持项目范围、物业类型和数据状态一致。

### 滚动窗口

- 近三个月：观察项目近期来访、成交、价格和转化变化。
- 近六个月：观察持销趋势和策略效果。
- 近十二个月：观察城市或板块市场大势、成交量价和供应周期。

任何滚动指标都必须标明窗口长度。

## 标准指标快照

实际数据使用 `../contracts/metric-snapshot.yaml` 传递。每个值保留分子、分母、公式版本、来源和质量状态，成果技能不得只接收脱离口径的单一数字。

## 待企业校准

- 明确销售合约额采用认购、草签、网签还是明源有效成交状态。
- 明确退订跨月后是否追溯调整历史期间。
- 明确有效客户和有效客储的公司标准。
- 已取得持销来访成交约10%、首开来访认筹约15%、认筹成交约60%的经验基准；仍需明确正式分子、分母、观察窗口及历史分布。
- 明确批复目标均价、底价和价格实现率口径。
- 已取得整盘约2.5%、首开阶段可至约3%并后续压降的经验基准；仍需明确费用科目、确认时点、费率分母、分摊和跨期规则。
- 明确实际回款和签约的财务、法务确认状态。
- 明确车位、商业和住宅是否使用相同指标公式。
- 补充现行经营报表中的正式字段名和系统来源。
