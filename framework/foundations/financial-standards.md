# 财务标准与经营边界

状态：`draft`

## 目的

为价格、费用、推售、资源申请和项目诊断提供统一财务语言。这里只定义应计算什么、怎样比较和何时需要审批，不预设企业利润底线和权限数值。

## 五类边界

### 1. 价格边界

区分以下价格：

- `startup_approved_price`：启动会确定的整盘均价及各业态均价。
- `opening_requested_price`：首开价格评审会申请的首开范围整体均价及各业态均价。
- `list_price`：对客户公开展示的房源价格。
- `approved_target_price`：其他经营方案或价格会批复的目标成交价。
- `current_net_price`：扣除已批准折扣后的当前成交口径。
- `proposed_net_price`：拟调整方案的预计净成交价。
- `approved_floor_price`：经集团审批备案的一房一价表对应房号底价，原则上实际成交价不得低于该价格。

净成交价是表价经过已批准优惠和折扣后的实际成交价格，应高于或等于对应房号底价。启动会批复价、首开申请价格和房号底价分别处于整盘/业态、首开范围/业态和单套房源三个层级，不得直接混用。

房源价格比较必须使用相同建筑面积、房源范围和资源折算口径。车位、家电、装修、物业费等赠送应折算资源成本，不能只比较名义房价。

### 2. 利润边界

`全投资计息`是统一的项目财务测算整体，报告中的“全计息”和“全投资”均视为简称，不拆成两套模型。住宅、商业和车位先分业态展示，再汇总到同一个项目利润框架。

至少观察：

- 预计销售收入和收入变化。
- 直接成本、税费和可归属资源成本。
- 毛利润金额和毛利率。
- 调价、赠送或加佣的增量利润影响。
- 不采取动作时的持有、资金和库存机会成本。

营销技能不得自行确认项目是否“亏损”。亏损状态必须使用财务确认口径，并说明是单批房源、项目动态利润还是公司会计利润。

全投资计息净利润、成本利润率、毛利率、净利润率和IRR等结果优先使用财务提供值。未提供专门公式时，仅按指标字面含义解释并标记 `待财务复核`，不得包装成企业正式公式。

### 3. 现金流边界

至少观察：

- 合同签署和回款节奏。
- 首付、按揭、公积金和分期款预计到账。
- 当期营销支出及已承诺未支付费用。
- 基准、谨慎情景下的净现金流和资金缺口。
- 价格换量对回款时间的影响。

销售额提升不自动等于现金流改善，必须同时检查签约和到账条件。

- 土地款回正：累计销售回款达到或超过已投入土地款的最早时点。
- 现金流回正：累计销售回款覆盖土地、工程、设计、营销及其他纳入项目现金流投入的最早时点，通常晚于土地款回正。

具体纳入哪些“其他费用”、使用计划回款还是实际回款，以项目财务版本为准。

### 合约额确认与退房冲减

- 销售合约额通常以明源正式签约金额为准，政府网签作为参考状态。
- 签约退房在退房审批完成并发生冲减的周期体现，不追溯改写原合约发生周期。
- 年度累计和历史趋势同时保留本期签约发生额、本期退房冲减额和净销售合约额，避免历史数据随退房反复改写。
- 认购反映销售流速，不直接替代正式合约额；回款由财务确认，并在半年、年度及专项风险节点检验销售质量。

### 精装修剔除

剔除精装修后的售价 = 带装修售价 - 精装修成本。单价计算必须保证售价和精装修成本采用相同面积单位；精装修成本值由成本或财务确认。

### 4. 营销费用边界

区分：

- `approved_budget`：正式批准预算。
- `committed_expense`：已签约或已下单但尚未全部确认的费用。
- `recognized_expense`：财务已确认费用。
- `paid_expense`：实际已支付金额。
- `forecast_expense`：按当前动作预计的期末费用。

费用方案同时比较预算余额、营销费率、增量客户或成交贡献以及退出条件。

经验控制基准：整盘累计营销费率一般按约2.5%管理；首开阶段可以将费用适度前置，阶段费率最高按约3%测算，后续持销阶段压降，使整盘累计费率回归约2.5%。使用时必须展示首开已用、后续可用和整盘预测三条线，不能只批准首开高费率而不铺排后续压降路径。

上述比例不是财务预算批复或刚性阈值。项目必须明确费用分子、合约或回款分母、确认时点、跨期分摊和审批权限。

### 5. 权限边界

价格、折扣、赠送、加佣、活动、编制和费用都应记录：

- 当前授权额度。
- 拟申请额度。
- 决策层级和会签部门。
- 有效房源、客户、渠道和时间范围。
- 到期后恢复或重新审批规则。

## 情景比较

重大价格和资源决策至少比较：

| 情景 | 含义 |
| --- | --- |
| 基准方案 | 按当前价格和动作继续经营 |
| 调整方案 | 执行拟议价格、费用或资源动作 |
| 谨慎方案 | 流速或转化低于预期 |

每个情景输出成交套数、合约额、净价、回款、费用、利润影响、库存周期和主要风险。

## 决策门槛

- 低于已批价格或新增资源必须走对应审批。
- 缺少底价、利润或现金流数据时，不给出“可以降价”的确定结论。
- 只增加费用但没有目标、归因和复盘机制的方案不得推荐。
- 用价格换量时必须说明新增成交是否足以覆盖单位让利和价格体系损失。
- 涉及老业主、合作方或公开价格体系时增加舆情和合同风险检查。

## 标准输入

使用 `../contracts/financial-context.yaml`，并与 `metric-snapshot` 保持项目范围和统计周期一致。

## 待企业校准

- 毛利、净利、动态利润和亏损项目的判定口径。
- 已取得整盘约2.5%、首开阶段可至约3%并后续压降的经验基准；仍需补充营销费用科目、费率分母、分摊和跨期确认规则。
- 集团、地区、项目各级价格、费用、加佣和赠送权限。
- 财务情景测算模板及税费、合作方约束；车位成本利润由财务专项测算。
- 回正口径纳入的其他费用、计划/实际回款选择和再次转负处理规则。
