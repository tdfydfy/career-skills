# 项目分类与阶段模型

状态：`draft`

## 目的

用相互独立的分类轴描述项目，不把“住宅、首开、困难、保利润”等不同维度混成一个项目类型。所有业务技能和成果技能先读取项目分类，再选择适用的分析方法和动作模块。

## 分类轴

### 1. 物业类型 `property_type`

| 值 | 定义 |
| --- | --- |
| `residential` | 住宅产品 |
| `parking` | 车位产品 |
| `commercial` | 商铺或其他商业产品 |
| `mixed` | 同一任务同时涉及多种物业，输出时仍需分别核算 |

库存不是物业类型，应通过库存结构和销售阶段表达。

### 2. 销售阶段 `sales_stage`

| 值 | 核心判断 | 进入条件草案 | 退出条件草案 |
| --- | --- | --- | --- |
| `positioning` | 明确市场、地块、客户、产品和价格方向 | 项目进入定位或启动决策 | 核心定位和产品方向获批 |
| `pre-launch` | 展示、蓄客、认筹和首开准备 | 首开节点明确并开始系统蓄客 | 首批房源正式销售 |
| `launch` | 首批或关键批次集中销售 | 房源、价格、优惠和选房规则释放 | 完成首开复盘并转入常态销售 |
| `sustained` | 持续来访、成交、加推和结构优化 | 首开后进入常态销售 | 剩余货量进入专项收尾管理 |
| `tail` | 针对剩余难售货量专项去化 | 库存集中、正常打法边际效用下降 | 达成清盘、交付或停止常规销售条件 |
| `delivery` | 交付、签约、按揭、回款和风险处置 | 项目进入集中交付或回款阶段 | 主要交易和客户问题闭环 |

加推是发生在 `sustained` 阶段的关键事件，不必单独作为长期阶段；需要完整开盘组织时，可临时采用 `launch` 工作模式。

### 3. 经营状态 `operating_status`

经营状态是在每周操盘、月度趋势和年度预计实现分析中逐步形成的管理判断，不单独依靠一次健康度评分。

| 值 | 定义 | 主要识别口径 |
| --- | --- | --- |
| `normal` | 年度合约额预计实现和当前经营节奏总体可控 | 年度合约额、剩余完成压力、认购流速和供货能力 |
| `key-difficult` | 需要重点关注、专项策略矫正或资源支持 | 典型信号为剩余可售不少于50套且连续两个月月认购低于10套 |
| `tail` | 剩余货量进入专项收尾管理 | 剩余可售房源不足50套，不再区分正常或重难点 |

状态判断按以下顺序进行：

1. 以年度合约额目标、截至当前节点累计完成和全年预计实现为主。
2. 计算后续月均合约额要求，并与近三个月月均合约额比较。
3. 月度指标只用于观察趋势和阶段偏差，结合市场、价格、房源、政策和后续供应解释。
4. 认购套数作为绝对流速和运营效率补充，不作为核心考核指标。
5. 来访、价格、签约周期、退房和回款作为原因分析或销售质量风险提示，不做平均评分。

项目月认购低于20套时，即使完成阶段指标，也存在售楼处和团队固定运营成本摊薄利润的问题，不视为健康流速。利润压力可以限制降价，但不把低流速重新定义为正常。

销售质量与经营状态并行记录：认购转明源签约平均3至7天通常正常，超过7天即不健康，超过14天属于高风险；认购或签约退房率超过5%提示风险。上述指标单独考核和提示，不直接决定 `operating_status`。

### 4. 战略任务 `strategic_role`

一个项目可有一个主任务和至多两个辅助任务：

- `benchmark`：树立价格、产品或品牌标杆。
- `profit`：优先守住价格和利润。
- `volume`：优先贡献销售规模。
- `cashflow`：优先形成签约和现金回笼。
- `inventory`：优先降低特定库存。
- `risk-control`：优先控制交付、客户或经营风险。

战略任务由集团、地区和项目共同确认，不能由成果技能根据单一指标自行推断。

### 5. 市场环境 `market_condition`

- `hot`：需求和流速较强，可评估集中释放和价格优化。
- `stable`：供需相对稳定，以结构和转化效率为主。
- `weak`：需求不足或竞争加剧，需要控制预期和资源效率。
- `structural-opportunity`：整体市场一般，但特定板块、时点、面积段或业态存在供需错配。

市场环境必须注明统计范围、统计周期和证据，不可只用主观感受判断。

### 6. 推售模式 `sales_mode`

- `concentrated-launch`：以明确节点集中蓄客、认筹、选房和成交。
- `continuous-sale`：持续释放、持续沟通、来客即转化。
- `batch-release`：按楼栋、产品或客户成熟度分批释放。
- `special-clearance`：针对顶底、特殊位置或尾货进行专项去化。

## 首开关键决策节点

### 启动会

在拿地后召开，确定项目整体策略、整盘及分业态价格、货值、利润和其他核心经营指标，是后续经营比较的重要基准。

### 首开价格评审会

在首次开盘前召开，通常距启动会三至六个月，决策首开范围、首开整体及分业态价格、首开销售套数、合约额和去化目标。期间经济技术指标和市场行情允许发生变化，但报告必须与启动会基准逐项对比，原则上尽量保持或超越启动会指标；未达到时说明原因、影响和补救方案。

## 待企业校准

- 明确各阶段正式名称以及进入、退出审批节点。
- 校准不同城市、项目规模和供货节奏下的绝对流速经验值。
- 明确除连续两个月低于10套外，其他进入和退出重难点管理的审批条件。
- 明确车位、商业与住宅的阶段差异。
- 明确集团对标杆、利润、规模、现金流任务的决策权限。
- 补充正常、困难和亏损项目各一个真实分类样例。
- 校准启动会至首开价格评审会超过或少于三至六个月时的例外处理。
