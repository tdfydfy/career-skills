# 营销成果策略推导标准

状态：`draft`

## 目的

让报告中的结论、目标和动作由同一条经营逻辑推导，而不是把市场、客户、推广、客储和预算章节并列拼接。所有成果都应保留可审查的逻辑暗线，项目营销策略报告需要把这条暗线显性呈现。

## 标准推导链

```text
公司经营意图与约束
  → 项目、产品、货量、展示和工程条件
  → 市场容量、竞争关系和窗口
  → 客户需求、承价、客储和抗性
  → 核心矛盾与机会
  → 策略命题及取舍
  → 价格、推售、价值和客户选择
  → 推广、展示、获客、销售和协同动作
  → 来访、认筹、成交、回款和费用目标
  → 监测、调整和复盘
```

## 六个逻辑接口

### 1. 公司意图到项目任务

说明集团、地区和项目分别优先规模、利润、现金流、标杆还是库存，并写明不能突破的指标、权限和节点。项目目标不是市场分析自然产生的，必须先有经营任务。

### 2. 市场客户到核心矛盾

市场回答容量、价格带、竞争和窗口；客户回答购买动机、产品选择、承价、抗性和成交条件。将两类证据与项目条件交叉，只保留一至三个真正影响目标的矛盾，不用“市场竞争激烈”等空泛判断代替。

### 3. 核心矛盾到策略命题

策略命题同时写明：争取谁、用什么价值或资源、解决什么矛盾、实现什么目标、放弃什么。每个命题至少比较一个备选方案，并说明选择和不选择的原因。

### 4. 策略到动作

每项重点动作必须指向某个矛盾或策略命题，并写清目标客户、目标房源、阶段任务、责任人、预算、前置条件、领先指标、结果指标和停止/调整规则。只有创意但没有经营作用的活动不进入主策略。

### 5. 动作到漏斗与预算

从销售目标反推认筹、有效客户、来访、线索和渠道目标。说明每层转化率的来源，将各渠道目标、动作量和费用与漏斗对应。不得一边给出销售目标，一边使用无法支撑目标的渠道和预算。

### 6. 结果到复盘

为市场、客户、价格、动作和费用假设设验证节点。实际结果偏离时，区分假设错误、执行不足和外部变化，再调整策略；不只检讨活动是否按时完成。

## 反模式

- 先想活动或传播口号，再倒找市场和客户理由。
- 罗列项目卖点，但不解释客户为什么在当前总价下购买。
- 用单个竞品价格直接推出本案价格，不考虑产品、客户和货量差异。
- 渠道成交占比、来访量和认筹量互相不能反推。
- 所有渠道都做、所有客群都要，没有资源取舍。
- 预算按历史比例分配，与目标和动作贡献无关。
- 把案例动作、行业流行做法或领导偏好写成项目事实。

## 最低质量门槛

- 每个核心结论至少有一个证据和一个经营含义。
- 每个主策略能回到核心矛盾和公司意图。
- 每个重点动作能回到策略、目标客户、房源和漏斗指标。
- 销售、认筹、来访、渠道目标和预算能够相互复算。
- 明确不做事项、失效条件和复盘时间。
