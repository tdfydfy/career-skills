# 房地产图片与平面视觉标准

状态：`draft`

## 目的

统一海报、主视觉、公众号配图、户型图、区位图和销售物料的事实表达、信息层级、素材来源及发布检查。

## 基本原则

- 先明确载体和信息任务，再设计视觉风格。
- 主视觉只承担一个核心信息，避免标题、卖点、价格和活动同时争抢注意力。
- 项目、产品和真实体验应成为主要视觉证据，不以纯氛围素材替代真实内容。
- 字体、颜色、Logo、安全区和项目标准色使用企业品牌文件；未提供时不得自行固化为品牌标准。
- 文字在目标尺寸下必须清晰可读，重要限制条件不能缩成不可识别小字。

## 素材类型

- 实景照片：记录拍摄时间、地点和必要修图边界。
- 效果图：显著标注“效果图”，不得当作已建成实景。
- 样板间：说明是否为交付标准，非交付内容按规定标注。
- 户型图：面积、朝向、尺寸和空间关系与审批及合同资料一致。
- 区位图：比例和位置不误导，规划、在建和已建资源状态清楚。
- 数据图表：坐标、单位、时间和来源完整，不通过截断坐标夸大变化。
- AI或合成素材：不得生成虚假项目实景、客户证言或交付效果；按平台和企业要求标识。

## 信息层级

建议按以下顺序组织：

1. 品牌或项目身份。
2. 本次唯一核心信息。
3. 支撑事实或活动信息。
4. 行动入口。
5. 证照、来源、条件和免责声明。

同一系列物料保持标题位置、字体体系、色彩、图片处理和免责声明位置一致。

## 交付检查

- 渠道尺寸、文件格式、清晰度和文件大小符合当前平台要求。
- 文案版本、价格、日期、地址、电话和二维码准确。
- 图片版权、人物肖像、字体和第三方Logo获得授权。
- 非实景、非交付、规划中和价格条件标注完整。
- 小屏预览、打印样张和不同屏幕下均可读。
- 源文件、导出文件和最终发布文件使用版本号管理。

## 待企业校准

- 企业VI、项目VI、字体、色值、Logo和安全区文件。
- 各平台当前尺寸和文件要求。
- 修图、AI素材和第三方素材使用政策。
- 标准免责声明字号、位置和模板。
- 设计审核、法务审核和发布权限。
