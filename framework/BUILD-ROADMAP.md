# Skill 网络建设路线图

## 当前完成度

- 基础层：11个节点均已形成草案模块。
- 业务层：23个节点均已形成工作流规格。
- 成果层：20个节点，其中17个形成编排配方，3个形成独立技能。
- 现有技能：6个保持独立目录和使用方式并接入依赖网络，高频成果接口按公共口径逐步校准。
- 首开成果：`launch-marketing-report` 已升级为项目首开营销策略报告技能，接入公司意图→市场客户→核心矛盾→策略动作→目标预算推导链，并通过一个正常首开虚拟案例前测。
- 首开价格成果：`launch-price-report` 已按现行25页文字模板形成独立技能；启动会与首开价格评审会、全投资计息、回正、精装剔除和价格边界已校准，真实案例前测待补。
- 持销成果：`sustained-sales-diagnosis` 已按问题导向升级为专题诊断技能，接入前期得失、多因素根因、非价格优先、价格产品升级门槛、权益替代、老业主保护和房车同售，并通过一个异常虚拟案例前测。
- 公共契约：项目、客户、组织、指标、事实、财务、动作、内容和成果接口已建立。

`draft` 表示框架、流程和通用专业基线已经具备，但仍需继续校准企业口径并完成适用场景验证；不等同于可直接投入生产的独立技能。

## 建设原则

1. 先校准基础口径，再把业务规格转成独立 `SKILL.md`。
2. 每次走通一条“基础 → 业务 → 成果”的纵向链路。
3. 基础信息和企业口径通过业务共创直接确认；具体成果在实际使用或前测时，再按需引用项目资料并补充规则，不追求一次性写完。
4. 财务、法务、价格和对外承诺必须由责任部门确认。
5. 现有技能先通过网络复用，公共口径和高频成果接口按需校准，确认复用价值后再决定是否进一步改造。

## 第一条纵向链路：项目诊断

```text
项目模型 + 指标 + 事实 + 财务 + 组织
  → 市场竞争 + 客户 + 销售 + 货量量价 + 利润 + 团队 + 动作 + 专项任务
  → 项目诊断报告
```

完成条件：

- 在具体诊断任务或成果前测中，按需引用不同管理关注度和利润状态的项目资料。
- 持续校准年度与月度销售任务、完成压力、绝对流速、销售阶段和管理关注度复核规则。
- 将 `business-analyze-project-health` 作为经营过程中的趋势与问题分析能力，为关注度复核提供证据，不初始化为独立健康度评分或自动分类技能。
- 将 `deliverable-project-diagnosis-report` 初始化为成果编排技能。
- 用至少两个不同项目前测并修订。

当前状态：已确认年度目标管理长期结果、月度任务管理短期执行且两者相互校验，并已取得后续完成压力、认购流速、尾盘、签约周期和退房风险口径；需继续共创经营监控输入、输出和实际案例。

## 第二条纵向链路：首开

```text
公司经营意图 + 项目 + 客户 + 指标 + 财务 + 事实
  → 市场 + 客储 + 核心矛盾 + 营销策略命题
  → 价格货量 + 价值推广 + 获客 + 展示 + 销售 + 目标预算
  → 项目首开营销策略报告
```

完成条件：继续校准首开阶段、有效客储、客储货量比、开盘窗口、转化费效基准和审批模板，并使用一个真实首开案例验证完整推导链。正常虚拟案例已完成；异常虚拟案例待补。

价格会子链路：

```text
公司经营意图 + 项目 + 客户 + 指标 + 财务 + 投资 + 事实
  → 市场竞品 + 客储 + 营销策略约束 + 住宅/车位价格货量 + 跨专业协调
  → 首开价格报告
```

当前已完成25页结构、ABCD客户评级、住宅和车位定价规则、启动会对比原则、全投资计息及价格口径、质量门槛和确定性复算脚本，并通过一个正常首开虚拟案例前测。正式投产仍需真实项目的财务测算结果、精装成本、原始PPT版式资产和脱敏数据前测；异常场景仍需另行验证。

## 第三条纵向链路：经营管理

```text
指标 + 组织 + 财务
  → 经营趋势与问题 + 管理关注度 + 客储 + 价格货量 + 费用
  → 周月经营汇报 + 年度/半年度报告
```

完成条件：导入正式经营报表、领导汇报模板和会议节奏。

## 第四条纵向链路：内容生产

```text
事实 + 文案 + 图片 + 视频 + 合规
  → 推广 + 软文 + 图文 + 图片 + 视频
  → 整合推广方案
```

完成条件：导入品牌手册、VI、渠道规格、优秀素材和审批流程。

## 建议实施顺序

1. 校准P0企业输入。
2. 完善项目经营趋势与问题分析和项目诊断报告编排。
3. 实现经营汇报、价格货量和调价报告技能。
4. 实现首开报告及其市场、客储、获客子技能。
5. 实现活动、推广和销售说辞成果技能。
6. 实现持销、尾盘、车位商业、困难和亏损专项技能。
7. 再评估现有技能的重叠和迁移，不提前重构。

## 激活标准

节点从 `draft` 进入 `active` 前必须：

- 企业专属P0输入已确认。
- 输入输出符合公共契约。
- 正常场景和异常场景各至少一个测试。
- 关键结论可追溯到事实或明确假设。
- 涉及财务、合规和对外承诺的审核链已配置。
- 通过网络自动校验和独立前测。
