# 分析类业务工作流

状态：`draft`

## business-analyze-market-competition

### 目标

判断城市、板块和竞争项目的供需、量价、客户流向及未来博弈，识别项目可以利用的结构性机会和主要风险。

### 输入

- 项目范围、物业类型、目标周期和战略任务。
- 近十二个月市场供应、成交、均价和去化周期。
- 当前竞品的产品、价格、货量、展示、渠道、动作和流速。
- 未来竞品、潜在土地供应、政策和二手房情况。
- 数据来源、截止时间和可比性说明。

### 工作流

1. 固定市场边界，不把全城数据直接替代项目真实竞争圈。
2. 分析近十二个月趋势，并拆到板块、面积段、总价段和业态。
3. 建立竞品矩阵，区分直接竞品、替代竞品和参照项目。
4. 判断竞企资金、规模和经营风格可能形成的动作，但标记为情景而非事实。
5. 识别未来三至十二个月供应窗口和客户分流。
6. 输出基准、进取、谨慎三种竞争情景。

### 输出

市场结论、竞品排序、供需机会、未来动作情景、对项目价格客储和推售的影响、数据缺口。

### 质量门槛

- 历史数据和未来预测分开。
- 竞品比较使用同面积、总价、交付和板块范围。
- 结构性机会同时有供应缺口和客户证据。
- 不把心理距离或板块偏好当作宣传可以轻易改变的变量。

### 待校准

正式市场数据源、竞争圈划分方法、竞品分级标准和更新频次。

## business-analyze-customer-reservoir

### 目标

从客户数量和质量出发，判断未来客储变化及其对业绩目标的支撑程度，并形成老客修复、新客获取、价值价格、渠道和加推房源等客户导向决策建议。

### 输入

客户数据契约、来访认筹认购签约漏斗、客户来源、项目房源和三阶段盘点状态。

### 工作流

1. 去重客户和客户组，检查关键字段缺失与个人信息权限。
2. 分析客户量：来访、认筹、认购、意向等级及其周月趋势，并按渠道、区域和产品拆分增减来源。
3. 分析客户质：年龄、家庭结构、工作、来源区域、渠道、动机、预算、产品需求、价格预期、成交周期、意向等级和抗性因素。
4. 使用ABCD及B/C加减级表达意向，并按MAN检查资金、决策角色、需求匹配、房源落位和具体障碍。
5. 宏观上按业绩目标、套均总价和适用转化率反推所需成交、认筹和来访客户量，优先采用项目真实转化率。
6. 微观上由项目销售经理逐客盘点需求、价格、决策、房源匹配、评级、障碍、预计成交时间和跟进动作，并汇总预计成交。
7. 对照宏观需求和微观盘点结果，解释客储缺口、重复房源落位或过度乐观判断，不强行取平均。
8. 预测未来客户数量和质量变化，说明新增、流失、转级、转化和外部节点假设。
9. 诊断差距来自数量不足、质量偏弱、产品错配、承价不足、成交周期过长、抗性集中还是转化执行问题。
10. 判断优先修复现有老客户，还是调转口径获取新客户；新客需明确目标区域、行业、渠道和触达方式。
11. 将客户结论转译为价值点、价格策略、房源加推、渠道、推广和销售动作建议，并说明客户证据。
12. 探索期输出客群假设，验证期输出策略验证，确定期输出节点预测；日常来访不强制分有效无效，纯活动客户通常不计入。

### 输出

客户量质现状和趋势、未来数量质量预测、业绩所需客储、客储缺口、客储成熟度、客储货量比、价格预期、房源落位、转化障碍，以及老客修复或新客获取、价值价格、渠道和加推房源建议。

### 质量门槛

- 客户数、客户组、认筹套数和房源套数不混用。
- 隐性需求和成交预测标注置信度。
- 未披露字段保持未知，不补造职业、预算和家庭关系。
- 预测注明统计窗口、已释放信息和可能变化条件。
- 每项策略建议能追溯到客户数量、质量、转化或抗性证据，不用单一客户意见代替总体判断。
- 微观预测注明销售经理、盘点时间和逐客依据；宏观与微观结果不一致时必须解释原因。

### 待校准

专题有效客储、MAN完成度、抗性分类、开盘预测以及不同阶段客户结构输出的企业标准。

## business-analyze-project-health

### 目标

在每周操盘和月度经营分析中判断年度合约额预计实现、后续完成压力、绝对销售流速和销售质量风险，识别需要关注或进入重难点管理的问题。该能力不单独生成健康度评分。

### 判断主线

1. 年度合约额：目标、累计完成、全年预计实现和剩余缺口。
2. 完成压力：后续月均合约额要求及其与近三个月月均合约额的比值。
3. 月度趋势：阶段目标完成和变化方向，并结合市场、价格、房源、政策和供货解释。
4. 认购流速：首开前三天及持销月度认购套数，用于判断绝对流速和运营成本效率。
5. 销售质量：认购转明源签约周期、认购退房、签约退房和回款风险，单独提示而不与状态混合评分。
6. 问题归因：来访、客户、产品展示、价格、货量、渠道、团队和执行用于解释结果，不预设八维平均权重。

### 工作流

1. 读取年度目标、月度分解、近三个月合约额、剩余有效销售月份、可售货量、认购和签约数据。
2. 以年度合约额为主，计算全年预计实现、后续月均合约额要求和完成压力比；月度指标只用于识别趋势和偏差来源。
3. 检查剩余货量：不足50套转入尾盘管理，不再区分正常或重难点。
4. 检查绝对流速：持销月认购30至50套通常较健康；低于20套提示运营效率偏低；剩余可售不少于50套且连续两个月低于10套时进入重难点关注。
5. 检查销售质量：平均签约周期超过7天、超过14天或认购/签约退房率超过5%时单独提示风险和核查要求。
6. 结合来访、价格、市场、客户、产品展示、货量、渠道、团队和政策找到异常转折点，区分症状、直接原因、根因、放大因素和约束。
7. 输出年度压力、趋势、状态建议、问题线索、证据、需要核验事项和干预优先方向，不自动生成完整专题方案。

### 输出

年度预计实现、完成压力比、月度趋势、认购流速预警、销售质量风险、正常/重难点/尾盘状态建议、问题线索和干预优先方向。

### 质量门槛

- 不做脱离年度合约额和操盘过程的综合健康评分。
- 套数只作为流速和运营效率参考，不替代年度合约额考核。
- 单月未完成不直接判定项目异常，必须判断全年预计实现和后续压力。
- 利润压力可以限制降价，但不把低流速重新定义为正常。
- 不把市场差作为所有问题的统一解释。
- 签约、退房和回款风险单独提示，不直接决定项目状态，也不因异常比例直接认定虚假销售。

### 待校准

不同城市和项目规模的流速校准、重难点项目退出条件、剩余有效销售月份折算规则及退房率客户队列口径。

## business-analyze-marketing-expense

### 目标

判断营销费用预算、投入结构、动作效率和期末风险，为继续、调整或停止投入提供依据。

### 输入

批准预算、已承诺、已确认、已支付和预测费用；营销动作；线索、来访、有效客户、成交和回款；财务科目和归因规则。

### 工作流

1. 对齐项目、物业、周期和财务确认口径。
2. 做预算与实际、承诺与支付、当期与累计差异分析。
3. 按媒体、渠道、活动、展示、销售和人员等科目拆分。
4. 按动作检查目标、执行和结果，区分沉没成本与未来可调整费用。
5. 对可归因投入计算单线索、首访、有效客户和成交成本。
6. 归因不足时只做整体或组合效率，不强行分摊成精确ROI。
7. 预测期末费率和现金支出，提出保留、优化、停止和新增建议。

### 输出

预算执行、费率预测、费用结构、动作效率、异常费用、调整方案和审批事项。

### 质量门槛

- 营销费率分子、分母和跨期规则明确。
- 不以曝光量替代有效客户和经营结果。
- 不因短期低成本否定必要的品牌、展示和长期投入，但必须说明目标与验证方式。

### 待校准

费用科目、确认时点、分摊规则、渠道归因窗口和效率基准。
